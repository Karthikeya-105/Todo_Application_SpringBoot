# Todo Application

A Todo Web Application built using Spring Boot.

## Features

- Add Tasks
- Delete Tasks
- Toggle Task Completion
- MySQL Database
- Thymeleaf UI

## Tech Stack

- Spring Boot
- Spring MVC
- Spring Data JPA
- Hibernate
- MySQL
- Thymeleaf
- Maven

## Run

1. Clone the repository
2. Create a MySQL database named `todo_app`
3. Update `application.properties`
4. Run the project
